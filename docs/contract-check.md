# Проверка согласованности контрактов

Документ задаёт проверки до реализации и приёмки. Он не утверждает, что проверки уже выполнены. Сверять нужно три уровня: CLI-команды, контракты Tool и внешний INTERMAGNET HAPI, описанный в контракте Import Tool.

## Сценарии

| Сценарий | Ожидаемый результат | Проверяемые документы |
|---|---|---|
| Импорт корректного запроса | CLI принимает команду по JSON Schema; Import Tool находит dataset в `catalog`, читает `info` и `data`, сохраняет тело ответа и метаданные в локальную БД; Job завершается `Completed` | CLI schema, Tool contract, architecture |
| Пустой период | INTERMAGNET отвечает HTTP 200 с HAPI status 1201 или 1200 и пустым потоком; импорт считается успешным, локальный набор имеет 0 записей | Tool contract |
| Неверный HAPI dataset или параметр | HTTP 404 / HAPI 1406 или 1407; Tool выдаёт типизированную ошибку, Job завершается `Failed`, набор не сохраняется как готовый | Tool contract, CLI schema |
| Неверный временной диапазон | HAPI 1402–1405 либо локальная проверка отклоняет команду до внешнего вызова; сырой набор не создаётся | CLI schema, Tool contract |
| INTERMAGNET недоступен | Сетевой сбой или HTTP 5xx / HAPI 1500–1501 после ограниченных повторов; Job становится `Failed`, ошибка CLI не раскрывает детали транспорта сверх безопасного сообщения | Tool contract, CLI schema, ADR 0002 |
| Повтор импорта с теми же ключом и параметрами | Возвращается прежний Job; второй внешний запрос не запускается | CLI request schema, ADR 0002, Tool contract |
| Повтор с тем же ключом, но другими параметрами | CLI получает `idempotency_conflict`; новый Job и внешний запрос не создаются | CLI schema, ADR 0002, Tool contract |
| Обработка существующего сырого набора | Processing Tool работает с локальным набором, создаёт новый Job и сохраняет отдельный результат со ссылкой на сырьё; исходный набор не меняется | Architecture, Tool contract, ADR 0002 |
| Неизвестный метод или некорректные параметры обработки | Ошибка CLI с кодом `method_not_supported` или `invalid_processing_request`; результат не публикуется | CLI schemas, Tool contract |
| Сбой вычисления или локальной записи | Job становится `Failed`; частичный результат не показывается как готовый, исходный сырой набор остаётся доступен | ADR 0001/0002, architecture, Tool contract |
| Чтение наборов без сети | Query Tool читает локальную БД; импортирующий HAPI Tool не вызывается | Architecture, Tool contract, CLI schemas |
| Неизвестный локальный набор | CLI возвращает `dataset_not_found`; внешний API не вызывается | CLI schema, Tool contract |
| Запрещённый переход Job | `invalid_job_transition`; состояние Job остаётся прежним | Architecture, ADR 0002, Tool contract |

## Инварианты

1. CLI описан машинно-читаемой JSON Schema; HTTP API приложения нет.
2. CLI — входной слой приложения; он не поднимает HTTP-сервер. Запрос и ответ CLI описаны отдельными определениями внутри одного файла `cli.schema.json`.
3. Только Import Tool обращается к INTERMAGNET. Processing Tool и Local Data Query Tool используют локальную БД.
4. Сырые и обработанные наборы имеют разные идентификаторы; результат связан с исходным набором, который не изменяется.
5. `Completed` означает, что набор и его метаданные сохранены локально.
6. HAPI `1201` — успешный ответ без записей, а не ошибка.
7. Ошибки HAPI отображаются в типизированные ошибки Import Tool, затем в согласованный JSON-ответ CLI.

## Перед сдачей

- Сверить endpoint и параметры HAPI в `tool-contract.md` с официальной документацией и текущими `capabilities` INTERMAGNET.
- Проверить, что schema CLI содержит все команды, указанные в Tool contract, и ответы CLI имеют общий формат.
- Убедиться, что `tool-contract.md` отделяет внешний HAPI от внутренних команд CLI и не выдаёт HAPI endpoints за операции локальной программы.
- Проверить сценарии `1200`, `1201`, HAPI 14xx и 15xx; успешный пустой ответ не должен создавать Job со статусом `Failed`.
- Проверить, что импорт сохраняет ответ источника до собственной обработки и последующая обработка не меняет сырой набор.
