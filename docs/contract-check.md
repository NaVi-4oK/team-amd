# Проверка контрактов

Черновик сопоставлен с текущим пониманием продукта: локальная программа, один внешний API для сырых измерений из разных обсерваторий, обработка сохранённого набора и чтение локальной базы. Точные формулировки и названия карт К1–К10 следует сверить с выданной преподавателем колодой перед сдачей.

| Карта | Проверяемая ситуация | Ожидаемое поведение | Где закреплено |
|---|---|---|---|
| К1 Двойной запуск | Пользователь повторил ту же команду импорта или обработки с тем же ключом | Возвращается прежний Job; второй импорт/расчёт не создаёт дубликат. Тот же ключ с иными параметрами — конфликт | `api/openapi.yaml`, ADR-0002 |
| К2 Неверный запрос | Пустой список обсерваторий/компонент, неверные даты или `start > end` | Запрос отклоняется до запуска Tool; для такой команды Job не создаётся | `api/openapi.yaml`, `tool-contract.md` |
| К3 Неизвестная обсерватория | Внешний API не распознаёт указанный идентификатор обсерватории | `ObservatoryApiTool` возвращает безопасную ошибку `invalid_import_parameters`; сырой набор не сохраняется как успешно загруженный | `tool-contract.md`, архитектура |
| К4 Повтор после ошибки | Импорт или обработка завершились в `Failed`, пользователь запускает попытку ещё раз | Старый Job сохраняет ошибку; новая попытка использует новый ключ и создаёт новый Job | ADR-0002, схема состояний |
| К5 Частичный ответ API | API вернул записи не для всего запрошенного периода либо указал неполное покрытие | Сырые записи не исправляются и не дополняются автоматически. Источник покрытия сохраняется в метаданных, если он предоставлен API; неизвестное покрытие не объявляется полным | `tool-contract.md`; формат метаданных требует уточнения после выбора API |
| К6 Ошибка обработки | Выбранный метод не может обработать входные записи | Job обработки переходит в `Failed`; сырой набор остаётся доступен и неизменён; processed-набор не публикуется как готовый | `tool-contract.md`, ADR-0001/0002 |
| К7 Секрет в ошибке | Внешний API вернул отказ в доступе | Возвращается `access_denied`; токен или другие секреты не попадают в сообщение пользователю | `tool-contract.md` |
| К8 Неверный ответ API | Внешний ответ невозможно разобрать или он не соответствует ожидаемой структуре | `invalid_external_response`; Job импорта завершается с ошибкой, частичный ответ не выдаётся за сохранённый полный набор | `tool-contract.md`, архитектура |
| К9 Чтение локальных данных | Пользователь открывает ранее сохранённый raw- или processed-набор без сети | `LocalDataQueryTool` читает локальную базу; внешний API не вызывается; отсутствие сети не мешает чтению | `tool-contract.md`, `api/openapi.yaml` |
| К10 Локальная база недоступна | Чтение или запись завершились ошибкой | Возвращается безопасная ошибка локального хранилища; Job не получает `Completed`, если набор не сохранён | ADR-0001, `api/openapi.yaml`, архитектура |

## Дополнительные риски, найденные при разборе

1. **Перезапись сырых измерений обработкой.** Если обработчик пишет поверх сырого набора, исходник невозможно повторно интерпретировать. Решение: хранить отдельный processed-набор со ссылкой на raw-набор; это закреплено в архитектуре и ADR-0002.
2. **Чтение незавершённой записи.** Если данные видны до фиксации сохранения, UI может показать неполный набор. Решение: публиковать набор только после успешной транзакции; при ошибке Job не становится `Completed`.
3. **Непрозрачный результат обработки.** Если результат не содержит идентификатор метода и параметров, его нельзя корректно интерпретировать повторно. Решение: сохранять `method_id`, параметры и ссылку на входной raw-набор в метаданных. Сами поля научного результата согласуются после выбора метода.

Проверка описывает ожидаемые свойства контракта. Она не утверждает, что API поставщика, локальная база или методы обработки уже реализованы и испытаны.
