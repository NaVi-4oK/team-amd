# Контракт Tool

Tool — адаптер одного внешнего источника геофизических измерений. Все адаптеры используют одинаковый интерфейс, чтобы Dispatcher не зависел от формата конкретного источника. Источник выбирается по имени зарегистрированного Tool; клиент не передаёт произвольный URL.

## Общий интерфейс

```text
GeophysicalSourceTool
    source_id: string
    fetch(request: FetchRequest) -> ToolResult
        raises ToolError
```

`fetch` выполняет запрос к источнику и преобразует его ответ в общую структуру `ToolResult`. Конкретный HTTP-клиент, адрес источника, авторизация и разбор его формата скрыты внутри адаптера.

## Что Tool получает

```text
FetchRequest
    station_id: string
    components: list[string]
    start: datetime
    end: datetime
```

- `station_id` — идентификатор станции во внешнем источнике.
- `components` — непустой список кодов запрашиваемых компонент.
- `start`, `end` — границы периода с часовым поясом; `start <= end`.
- Источник в `FetchRequest` не передаётся: он уже выбран через Registry.

До создания Job вызывающий слой проверяет наличие полей, непустые идентификаторы и список компонент, корректность дат, наличие часового пояса и порядок границ периода. Он также проверяет, что запрошенный источник зарегистрирован. Tool проверяет ограничения, специфичные для своего источника: допустимость идентификатора станции и кодов компонент.

## Что Tool возвращает

```text
ToolResult
    source_id: string
    measurements: list[Measurement]

Measurement
    timestamp: datetime       # UTC
    station_id: string
    component: string
    unit: string
    value: number | null
```

Tool разбирает ответ источника и сопоставляет его поля с общей структурой. Время приводится к UTC только когда часовой пояс исходного значения известен. Единицы и значения не угадываются и не исправляются. Отсутствующее измерение представляется как `null`, а не как ноль.

Пустой список `measurements` — допустимый успешный ответ: он означает, что источник не вернул измерений за период. Это не `ToolError`; Job может перейти в `Completed`, а общий валидатор укажет в отчёте нулевое число записей.

После ответа Tool общий валидатор проверяет обязательные поля и согласованность нормализованных записей. Он же выявляет точные дубли, конфликты разных значений для одной позиции и пропуски периода. Точные дубли можно убрать с отметкой в отчёте; конфликтующие значения отклоняют набор. Полнота вычисляется только при известном шаге измерений; иначе она отмечается как неизвестная.

## Ошибки Tool

При отказе адаптер возвращает типизированную ошибку:

```text
ToolError
    code: string
    message: string
    field: string | null
```

| Код | Когда возвращается |
|---|---|
| `invalid_parameters` | Станция или компонент не поддерживается конкретным источником |
| `access_denied` | Источник отказал в доступе; секреты и токены не включаются в сообщение |
| `source_unavailable` | Источник недоступен, запрос истёк по тайм-ауту или исчерпаны ограниченные повторы временной ошибки |
| `invalid_source_response` | Ответ нельзя разобрать или в нём нет необходимых данных, например известного часового пояса либо обязательной единицы |
| `response_too_large` | Ответ превысил допустимый размер и получение было остановлено |

При `ToolError` Dispatcher сохраняет безопасную причину и переводит Job в `Failed`. Ошибку начальной проверки запроса Tool не возвращает: вызывающий слой отклоняет такой запрос до создания Job. Ошибку неизвестного источника также возвращает API/Registry до запуска Tool. Ошибки доступа не повторяются с теми же данными доступа.

## Tool проекта

Оба адаптера реализуют `GeophysicalSourceTool` и возвращают одинаковый `ToolResult`; различаются только внутренним протоколом и правилами конкретного источника.

| Tool | Ответственность |
|---|---|
| `SourceAlphaTool` | Запрашивает измерения источника Alpha, проверяет поддерживаемые им станции и компоненты, разбирает ответ Alpha и сопоставляет его поля с `Measurement` |
| `SourceBetaTool` | Запрашивает измерения источника Beta, проверяет поддерживаемые им станции и компоненты, разбирает ответ Beta и сопоставляет его поля с `Measurement` |

`SourceAlpha` и `SourceBeta` — временные имена двух адаптеров: конкретные внешние источники и их реальные схемы ответов ещё предстоит выбрать и проверить. Эта таблица описывает требуемые реализации, а не заявляет, что подключения уже написаны.
